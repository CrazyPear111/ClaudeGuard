# Инструкция по модификации и сборке релиза (Продакшен)

## 1. Архитектура сборки (`build.ps1`)

В продакшен-архиве установщик `install_claude_guard.ps1` является **самораспаковывающимся** (single-file installer). Чтобы при правке кода вам не приходилось вручную экранировать вложенные кавычки и переменные (`$`, `@'`), скрипт `build.ps1`:
1. Читает чистые исходники из `src/core/`, `src/cli/` и `docs/`.
2. Кодирует каждый модуль в **Base64**.
3. Генерирует итоговый `install_claude_guard.ps1`, который при запуске у пользователя декодирует модули напрямую в байты на диск (`[IO.File]::WriteAllBytes`).
4. Автоматически проставляет правильные кодировки для Windows:
   - **UTF-8 без BOM** для всех `.bat`-файлов (иначе `cmd.exe` выдает ошибку `я╗┐@echo off`).
   - **UTF-8 с BOM** для всех `.ps1`, `.md` и `.txt` файлов (чтобы PowerShell 5.1 корректно читал кириллицу).
5. Упаковывает готовый комплект в `dist/ClaudeGuard_Installer-v<Version>.zip`.

## 2. Как вносить изменения в утилиту

### Изменение логики фонового контроля или сервисов проверки IP
Редактируйте `src/core/claude_guard.ps1` и `src/core/start_claude_safe.ps1`.
* **Важно:** в Windows PowerShell 5.1 по умолчанию включен устаревший TLS 1.0, поэтому в начале каждого скрипта, делающего HTTPS-запросы, обязательно должна оставаться строка:
  `[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12`

### Изменение правил Брандмауэра Windows
Редактируйте `src/core/update_claude_fw.ps1`.
* Сохраняйте паттерн атомарной замены (`ClaudeGuard_TempLockdown` -> удаление старых -> создание новых -> снятие замка), чтобы при обновлении Claude Desktop трафик не оставался без защиты ни на миллисекунду.
* Не изменяйте имя основного разрешающего правила (`ClaudeGuard Allow Amnezia IPv4`) и префикс `ClaudeGuard*`, так как на них завязаны диагностика и деинсталлятор.

### Изменение `.bat`-оберток
Редактируйте файлы в `src/wrappers/`.
* Не добавляйте в `.bat`-файлы сложную логику — их единственная задача: включить кодовую страницу `65001`, запросить права администратора через UAC и передать управление одноименному `.ps1`-скрипту.

## 3. Пошаговая сборка архива для отправки в прод

1. Откройте **PowerShell** в корне репозитория.
2. Запустите скрипт сборки, указав новый номер версии:
   ```powershell
   powershell.exe -ExecutionPolicy Bypass -File .\build.ps1 -Version "1.1.0"
   ```
3. Проверьте папку `dist/`:
   - Внутри появится папка `ClaudeGuard_Installer-v1.1.0` и архив `ClaudeGuard_Installer-v1.1.0.zip`.

---

## 4. Чек-лист тестирования перед отправкой пользователям

Перед публикацией нового архива распакуйте его в тестовую папку и проверьте 4 сценария:
1. **Чистая / повторная установка:** запустите `Install_Claude_Guard.bat` двойным кликом. Убедитесь, что нет ошибки кодировки в первой строке консоли, а в конце выводится `Фоновых процессов контроля : 1`.
2. **Диагностика:** запустите `Check_Claude_Guard.bat` — все 5 пунктов должны быть зелеными, без зависшего правила `ClaudeGuard_TempLockdown`.
3. **Блокировка другой страны:** переключите AmneziaVPN на любую страну кроме США, нажмите на ярлык `Claude (Safe US)` — должно появиться окно предупреждения на чистом русском языке (без знаков `???`).
4. **Рабочий режим:** переключите AmneziaVPN на США и запустите `Claude (Safe US)` — приложение должно открыться и не закрываться.
