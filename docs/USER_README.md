# Система защиты Claude Desktop (AmneziaVPN + US Geo-Guard)

Многоуровневая система защиты для предотвращения утечки реального IP-адреса или подключения к серверам Anthropic из неразрешенных регионов.

## Как устроена защита (4 уровня)

1. **Брандмауэр Windows (сетевой уровень):**
   - `ClaudeGuard Allow Amnezia IPv4` — разрешает исходящий трафик `claude.exe` **только** через виртуальный адаптер `AmneziaVPN`.
   - `ClaudeGuard Block All IPv6` — жестко блокирует весь исходящий IPv6-трафик на всех интерфейсах.
   - `ClaudeGuard Block [<Адаптер>]` — автоматически блокирует выход в сеть через все остальные сетевые адаптеры в системе (Wi-Fi, Ethernet, OpenVPN, WSL, USB-модемы и т.д.).
2. **Безопасный ярлык на рабочем столе (`Claude (Safe US).lnk`):**
   - Перед запуском программы проверяет статус адаптера `AmneziaVPN` и внешний IP через резервные HTTPS-сервисы (`Cloudflare Trace`, `ipinfo.io`, `api.country.is`). Если страна отличается от `US` или VPN выключен, запуск блокируется с выводом предупреждения.
3. **Фоновый сторож с кэшированием (`claude_guard.ps1`):**
   - Каждые 15 секунд в фоне обновляет кэш текущей страны (при отключенном VPN запросы в сеть не отправляются).
   - Через системную подписку WMI (`Win32_ProcessStartTrace`) мгновенно перехватывает любой запуск `claude.exe` (даже из меню «Пуск») и закрывает процесс при неверной стране.
   - Отслеживает появление новых сетевых адаптеров в Windows и мгновенно создает для них блокирующие правила.
   - Записывает причины срабатывания в журнал `guard.log`.
4. **Автообновление правил Брандмауэра (`update_claude_fw.ps1`):**
   - При входе в Windows, изменении списка сетевых карт и раз в час сверяет путь к `claude.exe`, атомарно пересоздает правила при обновлении версии и обновляет иконку ярлыка.
